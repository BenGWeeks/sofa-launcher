# Demo pictures

Used only by screenshot / demo mode (`npm run screenshot`), never by an installed launcher:
the package does not include this folder, and demo mode then draws plain placeholders.

- `camera-*.jpg`: made-up security-camera views (front door, garden, driveway, side gate,
  patio at night, nursery), generated for this project with an OpenAI image model. They show
  no real place and no people.
- `game-warships.jpg`, `game-city.jpg`, `game-farm.jpg`, `game-blocks.jpg`: original pictures
  generated for this project with an OpenAI image model, in the general style of their genres
  (naval action, big-city open world, farming, block building). They are **not** the artwork
  of any game and show no game's characters or logos. In the demo two of them stand behind the
  names of real games (World of Warships, Grand Theft Auto VI) so the Games row looks like a
  real living room; those names are their owners' trademarks, used only to say which game a
  tile would open, and no connection with or endorsement by those owners is implied. On a real
  install the launcher shows Steam's own header picture for each game instead.
- `game-space-zappers.jpg`: the banner of [Space Zappers](https://www.spacezappers.com/)
  (`og-image.png` on its site), fitted whole on black. It is that game's own picture, not ours:
  it is included at the request of this project's maintainer, who contributes to Space
  Zappers. It will be removed if the game's author asks.
